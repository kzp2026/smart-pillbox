# paper-repro-v2.1 发布说明

此版本把评论研究流程集中到experiment服务，V2论文实验中心和命令行复用同一需求、映射、审核及追溯实现。原站入口保持冻结，现有私有数据库、登录、产品隔离、历史、图片和归档功能保留；本次无数据库迁移。

## 方法与使用范围

- 10类需求为规则辅助归纳；BERTopic/KMeans用于独立主题结构分析，明确配置且没有失败回退。
- 研究准备先停在graph阶段，下载人工标注/审核材料。真实C组必须有真实审核路径；假模型和模拟审核只能用于独立测试。
- A/B/C共享通用约束、模型参数、任务、格式和输出预算。B加入需求/评论，C再加入审核路径；输入长度和完整请求被记录。
- 自动检查不评价方案质量。真实人工评分、独立方案计数和V1/V2配对各自保存；默认不生成显著改善结论。
- 严格文字provider失败不回退。真实模型调用仍需单独费用授权，发布和登录不会调用收费模型。

## 部署与复现

原站使用app.py，现有V2应用使用v2/app.py。登录页显示“研究方法：paper-repro-v2.1”，可核对实际加载的方法版本。requirements.txt声明网页直接依赖；精确论文环境仍按experiment锁文件安装，BERTopic另需锁定模型。

运行命令、人工材料和研究边界分别见根目录REPRODUCING.md、METHODS.md、DATA_CARD.md、EVALUATION.md。原始评论、私有run、验证日志和用户历史输出不作为本次新发布文件。verification下的本地交付记录可由研究者保留，重新验证使用experiment/verify_e2e.py和experiment/verify_preparation.py。
