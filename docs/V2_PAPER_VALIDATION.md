# 论文支撑能力验收（2026-09-05）

## 结论

网站已具备支撑“小论文系统实现、方法描述、可复现案例分析”的软件能力，但当前数据不足以证明算法优于基线、设计有效或获得专家认可。补齐真实来源说明、独立人工标注和专家/用户实验后，才能讨论这些效果结论。没有收到论文全文、研究假设或投稿要求，本验收不能替代论文内容审查。

## 实现范围

- V2 新增正式“论文实验中心”：来源卡、清洗、稳定评论 ID、关键词/主题、需求候选映射、可选 SnowNLP、规则对照/消融、候选模型预测导入。
- 同一 test ID 计算分类指标；真实评分按方案、维度、角色分组；拒绝未知/重复/非法/缺失预测，未提交人工输入时不造指标。
- 私有实验存档、历史重开、源码白名单快照、逐文件 SHA-256、环境记录、再次复现；DOCX/CSV/JSON/PNG/ZIP 下载。
- 旧流程“方案评分”明确改为材料完整性自动自检，空输入 0 分，不冒充专家实证。
- 原站冻结入口未改；不修改外部爬虫。没有生产 migration、收费调用、提交、推送或部署。

## 仍须补齐的研究证据

1. 来源平台、商品标识、时间、抽样标准、数据使用依据与完整匿名化复核。
2. 标注规则、独立 test 划分、真实人工真值、多人分歧仲裁与一致性证据；禁止用 test 调参。
3. 代表性的基线与候选方法运行记录；从同一 test 集比较。规则首命中消融不能代表对所有方法的优势。
4. 真实专家/用户招募、人数、盲评/顺序控制、同一量表的评分；按研究问题决定样本量及统计检验。
5. 如要主张工程可行性、用户体验或显著提升，另做原型/工程验证及相应统计论证。

当前结论应写“系统实现并完成可复现案例流程验证”，不应写“已证明方法显著优于基线”或“专家认可度高”。
